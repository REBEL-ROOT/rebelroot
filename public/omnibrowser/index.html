Frequently asked questions

Omni Browser (also known as OmniBrowser or Rebel Root Omni Browser) is a fast, privacy-first mobile web browser for Android developed by RebelRoot. Built on Mozilla GeckoView, it provides desktop-grade WebExtensions, built-in uBlock Origin ad blocking, hardware-encrypted vaults, and offline translation.
Yes, Omni Browser includes full Mozilla WebExtension controller integration, allowing users to directly install and run Firefox .xpi add-ons like uBlock Origin, Dark Reader, and Violentmonkey on Android.
Omni Browser operates with zero telemetry, includes a one-tap session incineration 'Burn' button to purge history and cookies, isolates private browsing sessions, and features an AES-256 encrypted hardware Safe Locker vault for private downloads.
Yes, Omni Browser is 100% free software released under the GPLv3 license without ads, paywalls, or data tracking.
