Media Hub

Omni treats video as a first-class citizen. A network-level sniffer finds streams the page tries to hide, hands them to a native player, and lets you download or extract audio — no third-party apps required.

How detection works

Most browsers only see what the page’s <video> tag exposes. Omni goes deeper with a dual-path detection system:

  • Extension path — the bundled Omni Media Grabber WebExtension watches network requests and hooks MediaSource/blob playback, then reports candidates to the app over native messaging (omniApp).
  • Native path — media/MediaInterceptor.kt inspects traffic at the engine level for HLS (.m3u8) and DASH (.mpd) manifests.

When a stream is found, Omni shows a grabber chip. Tap it to play or download.

Respect the law and creators

The grabber is a tool for your own media, offline viewing of content you’re entitled to, and accessibility. Don’t use it to infringe copyright.

The native player

Streams open in media/player/VideoPlayerScreen.kt, a full player built on AndroidX Media3 (ExoPlayer) with HLS and DASH support:

  • Gesture controls — swipe the left half for brightness, the right half for volume; double-tap to seek ±10s.
  • Playback speed — 0.25× to 3×.
  • Picture-in-picture — keep watching while you browse.
  • Background audio — via OmniMediaService, audio keeps playing with the screen off.
  • Fullscreen manager — immersive playback with system bars hidden.

Downloading streams

media/StreamDownloadEngine.kt downloads HLS and DASH streams segment-by-segment and stitches them into a single file. Progress, pause and resume are handled by the Downloads Manager.

// Simplified flow for an HLS download
suspend fun download(manifestUrl: String, target: File) {
    val playlist = parseM3u8(manifestUrl)      // resolve variants
    val segments = playlist.segments           // .ts segment list
    segments.forEachIndexed { i, seg ->
        fetchSegment(seg, target, index = i)   // download + append
        emitProgress(i + 1, segments.size)
    }
    finalize(target)                           // write container
}

Audio extraction with FFmpeg

Want just the soundtrack? Omni loads FFmpeg on demand — FFmpegLoader.kt downloads and extracts the native libav* libraries the first time you use it, so the APK stays small. FFmpegBridge.kt then extracts audio (e.g. MP3/AAC) from any downloaded video.

One-time download

FFmpeg is fetched once over the network and cached. After that, extraction works offline.

Batch media & manga

On gallery and manga sites, the grabber switches to batch mode: select many images or chapters at once with an interactive page selector, then download them as files or export to a single PDF. The fullscreen manga reader tracks your page and offers quick download as you read.
