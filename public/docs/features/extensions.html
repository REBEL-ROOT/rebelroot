Extensions

Because Omni runs the real Gecko engine, it supports genuine Firefox WebExtensions — the same .xpi add-ons you install on desktop Firefox, straight from addons.mozilla.org.

Why this matters

Most “extension-capable” Android browsers either have no extension support or a tiny curated store. Omni inherits GeckoView’s full WebExtension runtime, which means:

  • Install add-ons directly from addons.mozilla.org.
  • Run Manifest V2 extensions with background scripts, content scripts and the standard browser.* APIs.
  • Use extensions in private browsing (per-extension opt-in, enabled by default for bundled ones).

The bundled extensions

Three extensions ship inside the APK (assets/web_extensions/) and are installed by BuiltInExtensionManager on first run:

ExtensionVersionWhat it does
Omni Media Grabber2.1.0Sniffs HLS/DASH/MSE streams and reports them to the app via native messaging.
Omni AI Blocker1.1.0Hides AI overviews on Google, Bing, DuckDuckGo, Brave, Yahoo and more via CSS + a background script.
Omni Universal Copy1.0.0Restores text selection on sites that block it with user-select: none or script traps.

Each has a stable GeckoView ID (e.g. omni-media-grabber@omnibrowser.app) so updates replace rather than duplicate them.

Installing an extension

  1. Open the extensions panel

    Menu → Extensions, or open Quick Tools → Extensions.

  2. Browse addons.mozilla.org

    Navigate to AMO in a normal tab. Find an add-on and tap Add to Firefox — GeckoView intercepts the install.

  3. Grant permissions

    Review the requested permissions and confirm. The extension is installed and active.

  4. Manage it

    Toggle, update or remove it from the Extensions panel. Extension options pages open in a tab.

Extensions run with real permissions

A WebExtension can read and modify every page you visit. Only install add-ons you trust, and prefer well-known ones from AMO.

How the engine manages them

Extension lifecycle lives in browser/extensions/:

  • BuiltInExtensionManager — installs and updates the bundled set.
  • AiBlockerManager / UniversalCopyManager — feature-specific toggles wired into settings.
  • Runtime registration happens on the shared GeckoRuntime, so extensions persist across tabs and sessions.
// Bundled extensions are installed from APK assets
suspend fun installBuiltIns(runtime: GeckoRuntime) {
    listOf(
        "web_extensions/media_grabber",
        "web_extensions/ai_blocker",
        "web_extensions/universal_copy"
    ).forEach { path ->
        runtime.webExtensionController.ensureBuiltIn(
            "resource://android/$path", id = idFor(path)
        )
    }
}

Native messaging

Bundled extensions talk to the app over GeckoView’s native messaging channel (omniApp). The Media Grabber uses this to hand detected stream URLs to MediaInterceptor — a clean bridge between web content and native features.

Limitations

  • Manifest V3 support follows GeckoView’s evolving implementation; MV2 is fully supported.
  • Extensions that depend on desktop-only APIs (e.g. full downloads UI) may degrade gracefully.
  • There is no auto-update store UI — update bundled extensions via app releases, and AMO extensions manually.
