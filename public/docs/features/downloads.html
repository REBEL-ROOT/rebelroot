Downloads Manager

Omni ships a full download manager — not the bare system downloader. Queue, pause and resume anything, save straight to the encrypted vault, and batch-grab media.

What it handles

  • Standard files — anything served with a download disposition (PDFs, APKs, archives, images).
  • Streams — HLS/DASH video and audio captured by the Media Hub.
  • Images & pages — long-press any image to save it, or save the whole page as a clean PDF.
  • Batch media — multi-select images or manga chapters and download them in one go.

The downloads screen

Open it from the menu, Quick Tools, or Ctrl J. media/DownloadManagerScreen.kt gives you:

  • A live list with per-file progress, speed and size.
  • Pause / resume / cancel per item, with resume surviving app restarts.
  • Filtering by type (video, audio, image, document, other).
  • Open-with and share actions once a file completes.

Saving to the vault

When you download an image or save a page as PDF, the dialog offers two destinations:

DestinationWhere it goesProtection
DownloadsPublic Downloads/ folderNone — visible to other apps
Private VaultEncrypted app-private storageAES-256-GCM + biometric/PIN

Vault files are encrypted with AndroidX EncryptedFile and only decrypted inside the authenticated vault session. See Privacy & Security.

Page → PDF

Omni can print any page to a clean PDF via the Android PrintManager, stripping ads and banners first using the same blocking engine. Choose Save as PDF from the menu or Quick Tools.

Batch manga & image downloads

On supported gallery/manga sites, the grabber offers a batch selector:

  1. Open the grabber

    Long-press the page or use Quick Tools → Media Grabber.

  2. Select pages

    Tap to multi-select, or “Select chapter” to grab a range.

  3. Choose output

    Download as individual images, or export to a single PDF.

Downloads keep working in the background

Active downloads run on a foreground service, so you can switch apps or lock the screen without losing progress.
