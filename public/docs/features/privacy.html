Privacy & Security

Privacy in Omni isn’t a mode you turn on — it’s the default state of the browser. This page walks through every layer of protection and how to tune it.

The protection stack

Omni defends you at five distinct layers, from the network up to the UI:

LayerWhat it doesDefault
Content blockingCustom filter engine blocks ads, trackers and popupsOn
Engine isolationPrivate tabs run in a separate GeckoView contextOn
TransportTor routing and WireGuard VPN tunnelOff
StorageAES-256-GCM encrypted vault for sensitive dataOpt-in
Session controlFire Button burns everything in one tapReady

Ad & tracker blocking

Omni ships a custom blocking engine — not a WebView shim. It combines three techniques:

  • Network-level domain blocking — a bundled list of 180+ ad and tracker domains, plus downloadable filter lists (EasyList, AdGuard Base, Peter Lowe’s, Steven Black hosts, Fanboy Social).
  • Cosmetic filtering — a MutationObserver removes ad elements from the page as they appear.
  • Popup interception — engine-level onNewSession blocking stops window.open popups before they render.

A live counter tracks how many requests have been blocked, so you can see the engine working.

Managing filter lists

Open Settings → Privacy & security → Ad blocking to see your providers, update lists and view the block counter.

// Preset filter providers you can enable
val providers = listOf(
    "EasyList",          // general ads
    "AdGuard Base",      // ads + annoyances
    "Peter Lowe's",      // trackers
    "Steven Black",      // hosts-style blocklist
    "Fanboy Social"      // social widgets
)
Blocking is per-profile

Each browser profile keeps its own blocking state, so a strict work profile and a relaxed personal profile don’t interfere.

Incognito & private browsing

Incognito tabs in Omni are genuinely private: they run in a separate GeckoView private context, so cookies, cache and storage are isolated from your normal session and discarded when the tab group closes. Bundled extensions are allowed in private browsing by design (they run locally and send nothing out).

The Fire Button

The flame on your toolbar is a one-tap panic button. It:

  • Closes all open tabs
  • Clears cookies and site data
  • Empties the cache
  • Wipes browsing history

It’s implemented in privacy/FireButton.kt and is intentionally irreversible — that’s the point.

Tor

Omni includes a Tor client (privacy/TorManager.kt) that routes your traffic through the Tor network. It supports:

  • Bootstrap progress with live status
  • Bridges and Snowflake for censored networks
  • .onion addresses
Tor is slower by design

Expect higher latency. Tor is for when anonymity matters more than speed — combine it with the ad blocker for the cleanest experience.

WireGuard VPN

Omni can run a WireGuard tunnel (privacy/VpnManager.kt) using the official WireGuard Android library. Import a .conf file from any WireGuard provider and all browser traffic flows through the tunnel.

  1. Get a config

    Export a .conf from your VPN provider or self-hosted WireGuard server.

  2. Import it

    Settings → Privacy & security → VPN → Import config.

  3. Connect

    Toggle the tunnel on. A key icon appears in the toolbar while active.

The encrypted vault

The vault (tools/locker/) is a biometric- and PIN-protected space for sensitive pages, images and notes. Under the hood:

  • SQLCipher encrypts the Room database (AES-256).
  • AndroidX security-crypto EncryptedFile stores vault files with AES-256-GCM, keys in the hardware-backed Keystore.
  • Nothing is ever written to disk in plaintext.

When you download an image or save a page as PDF, Omni offers “Save to Private Vault” alongside the normal download.

Other protections

  • HTTPS enforcement — upgrades to HTTPS where possible.
  • Site permissions — per-site control of camera, mic, location and notifications.
  • No cleartext traffic — the app refuses plaintext HTTP for its own requests.
  • No telemetry — no analytics SDKs, no Firebase, no crash reporting to a server.
