AI Tools

Omni’s AI story is simple: give you control over where AI shows up. The headline tool is the AI Blocker, which strips AI-generated overviews out of your search results.

The AI Blocker

Search engines now inject large AI-generated answer blocks above organic results. If you’d rather see the actual web, the bundled Omni AI Blocker extension hides them.

It works with a content script plus an override.css stylesheet, targeting the AI overview containers on:

  • Google
  • Bing
  • DuckDuckGo
  • Brave Search
  • Yahoo
  • …and other engines as they add AI blocks

Toggle it

The AI Blocker is on by default. Control it from:

  • Quick Tools → AI Blocker for a one-tap toggle.
  • Extensions panel to disable it entirely.
  • The keyboard shortcut Ctrl B (with an external keyboard).
It’s local, not a filter service

The blocker runs entirely on your device as a content script. Nothing about your searches is sent anywhere — there is no server involved.

How it works under the hood

The extension is a Manifest V2 WebExtension with two moving parts:

{
  "manifest_version": 2,
  "name": "Omni AI Blocker",
  "version": "1.1.0",
  "content_scripts": [
    {
      "matches": ["*://*.google.com/*", "*://*.bing.com/*", "*://duckduckgo.com/*"],
      "css": ["override.css"],
      "js": ["background.js"],
      "run_at": "document_start"
    }
  ]
}

override.css hides the known AI-overview selectors immediately, and background.js watches for dynamically injected blocks so they’re removed even on single-page search UIs.

Translation

Omni also includes a translator (tools/TranslationManager.kt) for pages and selected text across many languages. Select any text and choose Translate from the selection menu.

Translation is currently online

Earlier builds used on-device ML Kit translation; that was removed for FOSS compliance. Translation now uses a free online endpoint, so translated text leaves your device. Don’t translate sensitive content.

Speak Aloud

The selection menu also offers Speak Aloud, which reads selected text using the system text-to-speech engine — handy for accessibility and long-form reading.

The philosophy

Omni deliberately keeps AI optional and local. There is no always-on assistant listening to your browsing, no cloud profile being built from your queries. The AI that is present exists to be turned off — and the rest runs on your terms.
