## Re-thinking Astrological Software

Most astrological services require sending coordinates, birth dates, and exact times to remote servers to generate birth charts. This data is deeply personal and easily linkable to individual profiles. 

Ved Astra was built to solve this privacy gap by running all astronomical planetary calculations entirely inside the user's browser.

## Pure Client-Side Math Engines

To compute astrological coordinate maps (Kundalis) and planetary positions, Ved Astra utilizes custom implementations of planetary ephemeris formulas. By compiling celestial motion coefficients directly into standard client-side modules, we calculate relative planetary positions for any date from 1800 to 2100 with millisecond precision.

- **Offline Chart Plotting**: Once loaded, the engine functions fully offline.
- **Dynamic SVG Rendering**: Charts are generated as custom vector assets, ensuring clean scaling on all display types.
- **Zero Query Latency**: Generating charts takes less than 20ms on standard mobile hardware.

## Generating Coordinates Dynamically

We use native trigonometric calculations to compute the relative houses (bhavas) and ascendant lines without requesting remote calculations:

// Simple calculation helper to compute celestial longitude coordinate offsets
function computeLongitudeOffset(rightAscension, declination, localSiderealTime) {
  const raRad = (rightAscension * Math.PI) / 180;
  const decRad = (declination * Math.PI) / 180;
  const lstRad = (localSiderealTime * Math.PI) / 180;
  
  const hourAngleRad = lstRad - raRad;
  const altitude = Math.asin(
    Math.sin(decRad) * Math.sin(0.707) +
    Math.cos(decRad) * Math.cos(0.707) * Math.cos(hourAngleRad)
  );
  return altitude * (180 / Math.PI);
}
