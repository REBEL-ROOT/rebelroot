## Shrinking the Footprint

Mobile web browsers are notoriously resource-intensive. Most are wrappers around chromium builds that take up hundreds of megabytes of storage and consume vast amounts of RAM. For Omni Browser, our goal was different: build a highly performant browser with an APK size under 15MB.

Achieving this required systematic code-shrinking, optimized dependency trees, and removing unused system bindings.

## Strip Unused System Classes

Standard Android builds bundle extensive diagnostic and tracking libraries by default. We systematically stripped out dependencies like Firebase Analytics, Play Services, and secondary telemetry layers. 

We then optimized our ProGuard/R8 configurations to aggressively prune unreachable code execution branches during build cycles.

## Native Render Optimizations

Instead of shipping a bundled Chromium rendering engine (Blink), we optimized Omni Browser to leverage the system's pre-installed WebKit libraries. By interface-binding directly via native Android wrappers and custom Javascript filters, we achieved high-fidelity rendering without the file size overhead.
