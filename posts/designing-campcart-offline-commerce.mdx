## Simplifying Independent E-commerce

Adding e-commerce to a static website usually requires loading heavy, tracking-laden third-party widgets or maintaining a complex backend database. These solutions introduce security vulnerabilities, drag down performance, and profile visitors.

CampCart provides an alternative: a zero-dependency, secure shopping cart widget running purely in the browser.

## Under the Hood: Pure Client-Side State

CampCart relies on a robust JavaScript state machine that manages product entries, quantities, and price calculations on the client. It persists cart items in `localStorage` securely to preserve the shopping state across page reloads.

- **Zero API Calls for Browse & Cart Management**: Keeps your site loading instantly.
- **Privacy-Enhancing Design**: No user data is sent to RebelRoot or third parties during shopping.
- **Highly Customisable UI**: Built with vanilla Web Components, allowing seamless integrations into any Hugo, Jekyll, Next.js, or HTML static page.

## Secure Checkouts

Checkout payloads are cryptographically signed on the client side before redirecting to payment aggregators. This prevents price-tampering attacks without needing a database to cross-reference prices:

// Simple cryptographic payload signing to verify order integrity
async function signOrderPayload(payload, privateKeyPem) {
  const encoder = new TextEncoder();
  const data = encoder.encode(JSON.stringify(payload));
  const signature = await window.crypto.subtle.sign(
    { name: 'RSASSA-PKCS1-v1_5' },
    privateKeyPem,
    data
  );
  return btoa(String.fromCharCode(...new Uint8Array(signature)));
}
