
# Omni Browser — "Living Intelligence" Cinematic Product Page

Rebuild `/omnibrowser` as an award-grade, scroll-driven experience that surpasses Arc Search + Superlist, while preserving every byte of the current page's SEO. Built as a **self-contained static site in `public/omnibrowser/`** (the same pattern as the docs we shipped), so it cannot break the rest of the Next app and gets its own isolated design language.

## Important: two intentional design languages on one domain
- **Docs (`/docs`)** stay flat / native RebelRoot red (a reading tool).
- **Omni hero (`/omnibrowser`)** becomes cinematic deep-black + aurora + glass (a marketing showpiece).
These are deliberately different surfaces — like Vercel's glossy marketing vs its flat docs. I will NOT touch the docs' flat styles.

## Routing (per your decision: replace)
- New experience → `public/omnibrowser/index.html` (served at `/omnibrowser` once the React page is gone — same mechanism that made `/docs` work).
- **Delete `pages/omnibrowser.tsx`** (recoverable from git). Keep `pages/omnibrowser/privacy-policy.tsx` (serves `/omnibrowser/privacy-policy`; no conflict with the static index).
- Homepage Omni section, `/features` card, and footer already link to `/omnibrowser` via string hrefs → they now hit the new page with zero edits.

## Design system (`styles.css`) — tokens
- Background `#050505`; surfaces glass `rgba(255,255,255,.06)` + hairline `rgba(255,255,255,.1)`.
- Aurora stops: electric blue `#3b82f6`, violet `#8b5cf6`, emerald `#34d399`.
- Text `#f5f5f7` / muted `#a1a1aa` (AA on black). Dark-only (brief).
- Type: **Space Grotesk** headlines + **Inter** body (Google Fonts preconnect, matching rest of site). Massive spacing scale; large editorial hierarchy.
- Grain: inline SVG `feTurbulence` data-uri overlay (no dep). Aurora: custom `<canvas>` (no Three.js — lighter, hits the brief's 60fps/fast-load goal; Three.js noted as optional future).
- Rounded geometry, soft volumetric glows, floating depth layers.

## Page structure (`index.html`)
1. **Floating minimal nav** (transparent → solidifies on scroll): Omni mark + name · [Docs] · [GitHub ★ live] · [Download]. No marketing Navbar (brief = minimal chrome).
2. **Cinematic hero** (100vh): centered floating Android phone mockup whose UI "breathes"; animated aurora behind; cursor-reactive tilt (disabled on touch + reduced-motion); H1 "The browser that thinks before you click."; subhead; CTAs [Download for Android] [Watch Demo]; scroll cue.
3. **Pinned scroll story** (GSAP ScrollTrigger pin, ~500vh) — ONE phone frame, 5 layered "screen" panels cross-morphed by scroll progress (no hard cuts = the "living browser / shared-element" feel), with editorial copy cross-fading in a side column:
   - Ch1 Search→conversation: URL field → AI prompt → instant answer → source cards.
   - Ch2 Browse for Me: tabs fan out → AI scans → collapse into one synthesized page.
   - Ch3 Compare: split-view emerges, diffs highlight, AI summary.
   - Ch4 Memory: history → semantic timeline; "that article about quantum batteries" retrieves instantly.
   - Ch5 Private by design: color drains to monochrome, trackers/ads/cookie banners dissolve, shield pulses once.
   - Timeline mapping: progress [0–1] split into 5 windows; each screen eased opacity + small y/scale; copy blocks likewise.
4. **Feature grid** (12 cards: AI Search, Browse for Me, Split View, Memory Search, Reader Mode, Privacy Shield, Ad Block, Extensions, Workspace Tabs, Voice Search, Offline Reading, Cross-device Sync) — stagger-reveal upward on scroll.
5. **SEO-preserved substantive sections** (real static markup, so no regression): the 16-row comparison table (Omni vs Chrome/Brave/Firefox), the roadmap (shipped v1.0–v1.2.2 + planned v1.3+), and the 4 FAQs as an accessible accordion.
6. **Social proof** (minimal, dev-focused): live GitHub stars (same `REBEL-ROOT/omni-browser` fetch), open-source/GPLv3 badge, performance metrics, 2–3 testimonials.
7. **Final sequence**: phone zooms out, aurora expands to a glowing horizon + subtle globe; H2 "The future of browsing isn't faster. It's smarter."; CTAs [Download] [Join Beta] [View Open Source].
8. **Minimal footer**: RebelRoot, links incl. Docs + Privacy + License + GitHub.

## SEO preservation (baked into `index.html` `<head>` + body)
Reuse the current page's exact payload so nothing is lost:
- `<title>`, `description`, the keyword string, `ogImage /ic_omni_logo.webp`, canonical `https://www.rebelroot.xyz/omnibrowser`.
- JSON-LD: `SoftwareApplication` (with the `alternateName` list), `BreadcrumbList`, and `FAQPage` (the 4 verbatim Q&As).
- GitHub stars: same build-time value not available statically, so fetch client-side on mount exactly as the old page did (endpoint + silent fallback to "—").
Static HTML + JSON-LD is *more* crawlable than the old client-hydrated React page → net SEO neutral-to-positive.

## Motion / interaction (`app.js`)
- **Lenis** smooth scroll (gated off under `prefers-reduced-motion`).
- **GSAP + ScrollTrigger**: hero parallax; the pinned 5-chapter morph; feature-card stagger; final zoom-out.
- **Canvas aurora**: rAF loop, paused on `visibilitychange` hidden; under reduced-motion → static gradient, no animation.
- **Cursor tilt** on hero phone (pointermove; disabled on coarse pointers + reduced-motion).
- **IntersectionObserver** reveals for grid + social proof.
- **Mobile**: pin disabled; chapters become stacked full-height sections revealed on scroll; aurora lighter. Standard responsive scroll-story fallback.
- **a11y**: skip link, semantic landmarks, keyboard-navigable nav/accordion/CTAs, focus-visible rings, AA contrast, full `prefers-reduced-motion` static fallback.
